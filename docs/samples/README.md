# 真实样本使用说明

真实面试样本只能放在本地或受控存储里，不要提交到仓库。

## 推荐存放方式

- 视频文件本体：放在仓库外，或放在已被忽略的本地目录中。
- 测试用 `.mp4` 公网链接：只保存在你自己的密码管理器、本地笔记或临时环境变量里。
- 如果需要 repo 内本地副本，建议放到 `backend/data/samples/`，这个目录不会进入 git。

## 禁止事项

- 不要把真实候选人视频提交到 `git`
- 不要把带鉴权参数的临时下载链接写进源码、README 或测试文件
- 不要把候选人姓名、邮箱、手机号等信息写进固定测试样例

## 手工回归建议

1. 准备一条可访问的 `.mp4` 链接，时长建议 30 到 60 分钟。
2. 在 `API Key 管理` 中创建一个只用于本地调试的模型配置。
3. 在 `视频剪辑` 页面粘贴视频链接，跑完整条链路。
4. 每次修改筛选逻辑、prompt、导出逻辑后，都重复同一条样本做回归比较。
