# 本地测试与冒烟流程

## 自动化测试

运行整套自动化测试：

```bash
bash scripts/test.sh
```

单独运行后端：

```bash
cd backend
python3 -m pytest tests -q
```

单独运行前端：

```bash
cd frontend
npm test
npm run build
```

## 手工冒烟清单

1. 启动本地服务：

```bash
bash scripts/dev.sh
```

2. 打开前端：
   `http://127.0.0.1:5173`

3. 在 `API Key 管理` 中完成：
   - 新建中文配置
   - 测试连接
   - 保存默认配置

4. 在 `视频剪辑` 中完成：
   - 输入公开 `.mp4` 链接
   - 填写候选人姓名和岗位/备注
   - 选择模型配置
   - 设置 30 到 45 秒目标时长
   - 点击 `开始 AI 剪辑`

5. 验证生成链路：
   - 任务进入加载态
   - `AI 推荐片段` 页面出现
   - 可以点击 `保留` / `移除`
   - 点击 `提交审核并导出`
   - 页面出现 `下载成片`

## 回归重点

- 侧边栏文案保持中文
- `视频剪辑` 和 `API Key 管理` 路由都能正常渲染
- review 页面能拉到高亮片段
- export 页面能给出本地导出文件路径
